2 Uji pemberitahuan di HP

3 Hubungkan Firebase Cloud Messaging

Tempel kunci publik Web Push (VAPID) dari proyek Firebase g-smart-guyangan, lalu buat token untuk perangkat ini. Jangan masukkan private key atau service account. Kunci publik tidak disimpan di server.

Untuk tes pesan sungguhan: Firebase Console → Messaging → Send test message → tempel token di atas. Latarbelakangkan halaman/PWA, lalu periksa notifikasi HP.
